macOS Clash完整配置使用教程

📅 2026年11月9日 🏷️ macOS教程 ⏱️ 阅读时间：8分钟

针对搭载 Apple Silicon (M1/M2/M3/M4) 与 Intel 芯片的 Mac 苹果电脑，详解 Clash Verge 和 ClashX 的安装、八戒机场订阅导入及全局规则设置。

准备工作

在开始配置之前，请确保完成以下准备：

  • 拥有 macOS 联网设备（系统已更新至稳定版本）
  • 已获取八戒机场订阅节点链接：前往八戒机场官网注册获取
  • 确保本地网络连接通畅，未开启其他冲突的代理应用

第1步：下载并安装 Mac 客户端

推荐下载开源现代化的 Clash Verge Rev 或 ClashX Meta 安装包（.dmg 格式）。双击打开并将应用拖入 Applications 应用程序文件夹。

首次打开如果提示“未受信任的开发者”，请在 macOS 的“系统设置 -> 隐私与安全性”中点击“仍要打开”授权即可。

第2步：获取八戒机场订阅并导入

登录八戒机场用户后台，进入“仪表盘”或“我的订阅”，复制专属 Clash 订阅链接。

在客户端中打开“订阅/配置”界面，点击“新建”或直接粘贴订阅 URL，点击“保存并更新”，节点列表将自动下载完成。

第3步：选择高速节点并开启系统代理

在节点列表中选择延迟较低的香港、日本、新加坡或美国优质专线节点。勾选“系统代理 (System Proxy)”并选择“规则 (Rule) 模式”，即可开启无缝全球加速。

常见问题与解答 (FAQ)

M系列芯片 Mac 应该选哪个版本？

+

请下载带有 arm64 或 Apple Silicon 标识的 dmg 安装包，原生运行效能更高且耗电极低。

开代理后 Safari 无法打开网页怎么办？

+

请检查是否已在客户端开启“系统代理”，或确认配置文件中的节点是否正常存活与延时通畅。
