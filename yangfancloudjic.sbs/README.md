## 部署说明

### 1. 上传文件
将所有文件上传到服务器根目录

### 2. 配置域名
确保域名 `yangfancloudjic.sbs` 正确解析到服务器

### 3. 配置HTTPS
推荐使用Let's Encrypt免费SSL证书

### 4. IndexNow设置
```bash
# 首次提交URL到搜索引擎
node indexnow-submit.js

# 建议设置定时任务，每天自动提交
# Linux crontab示例：
# 0 2 * * * cd /path/to/site && node indexnow-submit.js
```

### 5. 搜索引擎提交
- **Google Search Console**: 提交sitemap.xml
- **Bing Webmaster Tools**: 上传BingSiteAuth.xml，提交sitemap
- **百度站长平台**: 提交sitemap和主要URL
