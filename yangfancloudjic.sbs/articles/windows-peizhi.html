Windows配置教程

一、下载Clash for Windows

1. 访问扬帆云机场用户中心
2. 下载Clash for Windows客户端
3. 解压到合适位置

二、导入订阅

  1. 打开Clash for Windows
  2. 点击"Profiles"
  3. 粘贴订阅链接
  4. 点击"Download"

三、选择节点并启用

  1. 点击"Proxies"选择节点
  2. 点击"General"
  3. 开启"System Proxy"
  4. 访问google.com测试

四、模式选择

  • Rule：推荐，智能分流
  • Global：全局代理
  • Direct：关闭代理
