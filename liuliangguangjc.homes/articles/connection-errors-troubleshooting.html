一、 排查第一步：厘清代理链路的“五层传递模型”

很多新手在遇到科学上网故障时，往往表现得手足无措，要么狂点重启按钮，要么直接抱怨“机场又挂了”。 其实，从你的电脑点击一个网页，到数据最终从海外服务器返回，中间经历了一个清晰的五层传递路径：

你的浏览器 ➔ 系统代理设置 (127.0.0.1:7890) ➔ 客户端内核 ➔ 本地宽带 ➔ 机场国内入口 ➔ 海外节点 ➔ 目标网站。

只要我们学会顺着这条链路逐步定位，99% 的常见连接问题都可以在两分钟内迎刃而解。

二、 科学上网最常见的五大报错原因与对应解决方案

1. 报错现象：所有节点全部显示“Timeout”或延迟为 0ms - **根本原因排查**： - **原因 A（占80%）**：本地系统时间不准确。现代加密协议有严格的时间戳重放攻击防御，只要你的电脑时钟快了或慢了 60 秒以上，握手数据包就会被服务端直接丢弃； - **原因 B**：本地网络防火墙或第三方杀毒软件拦截了客户端的本地出网端口。 - **解决方案**： 打开 Windows 设置中的“时间和语言”，点击 **「立即同步」** 同步网络时间；同时检查杀毒软件，将代理客户端添加至信任白名单。

2. 报错现象：节点测速正常有延迟，但浏览器打不开任何网页 - **根本原因排查**： 客户端虽然在后台运行，但操作系统的“系统代理”开关没有成功打开，或者之前异常关机导致注册表中的代理端口残留错乱。 - **解决方案**： 在 Windows 设置中搜索“代理”，检查“使用代理服务器”是否处于打开状态，并确认端口号是否与 Clash Verge 中显示的混合端口（默认 7890）一致。或者在客户端设置中先关闭系统代理再重新开启。

3. 报错现象：提示“您的连接不是私密连接 (NET::ERR_CERT_COMMON_NAME_INVALID)” - **根本原因排查**： 开启了某些软件的 MITM 解密或去广告插件，导致浏览器无法识别中间自签证书；或者是公共网络（如酒店 WiFi）存在强行重定向认证页面。 - **解决方案**： 在公共场所使用代理前，先在关闭代理的状态下完成酒店/咖啡厅 WiFi 的手机号或网页登录认证，再开启科学上网客户端。

4. 报错现象：能够正常访问 Google，但无法使用 ChatGPT 或部分海外银行网站 - **根本原因排查**： 目标网站启用了针对机房 IP 的严格访问限制，或者客户端的分流规则库未及时更新。 - **解决方案**： 在客户端中右键订阅选择“更新订阅”以获取最新规则，并将策略组切换至 **流量光机场** 专门配置的“AI 专线”或“原生住宅落地”节点。

三、 终极排障秘籍：五步一键自检法

下次再遇到网络断连时，建议按顺序默念以下五步自检口诀： 1. 看时间：系统右下角时钟是否与北京时间分秒不差？ 2. 看状态：客户端左侧是否正确激活了最新订阅？节点连通性测试是否有绿字？ 3. 看模式：当前是否处于「规则模式 (Rule)」而非 Direct（直连）？ 4. 看开关：系统代理（System Proxy）开关是否亮起？ 5. 换节点：如果单一节点维护，手动切换到同一国家或地区的备用专线（例如从香港01切至香港02）。
