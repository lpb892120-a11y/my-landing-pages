请认准官方安全下载渠道，切忌在来历不明的第三方网盘或贴吧论坛下载被植入后门木马的“修改版”。

安装步骤极其简便：

启动 Clash Party 客户端后，进入初始配置环节：

  1. 在左侧导航栏中点击“Profiles (配置管理)”。
  2. 在顶部的输入框中粘贴您在流量光官网复制的专属订阅 URL。
  3. 点击右侧的 “Download (下载/导入)” 按钮。软件将自动解析服务端的最新节点池，耗时通常只需 1-3 秒。
  4. 导入成功后，配置卡片会显示订阅名称、节点总数（例如 68 个优质节点）以及到期时间和剩余流量信息。

五、四大核心分流模式详解：规则与全局怎么选

Clash Party 继承了规则引擎的精髓，提供了四种工作模式。搞清楚它们的工作原理，能让你上网快人一步且省流量：

  • Rule (规则分流 - 强烈推荐 99% 的用户日常开启)：核心优势在于“内外分流、按需代理”。访问国内的百度、知乎、腾讯视频直接走本地宽带直连，速度最快且不耗费机场流量；只有访问 Google、YouTube、Twitter、GitHub 等境外受阻站点时，才自动通过流量光专线中转。
  • Global (全局代理)：无论访问国内还是国外网站，全部强制通过所选的代理节点转发。此模式通常用于排查网站区域限制、测试海外特定 IP 归属地，但会导致国内微信或网易云音乐变慢，平时不建议常开。
  • Direct (完全直连)：相当于关闭代理加速，所有流量直接走本地网络，等同于未开启梯子。
  • Script / Merge (高级脚本模式)：面向高阶技术极客，支持使用 YAML 或 JavaScript 动态编写根据请求头、端口、协议匹配复杂网关的策略。

六、进阶技巧：开启 TUN 模式与防止 DNS 泄漏

为了达到真正的“隐身出海”和“全量加速”，推荐配置以下两项高级设置：

1. 开启 TUN 模式（虚拟网卡全局捕获）

进入客户端的“Settings (设置)”页面，找到 “TUN Mode (虚拟网卡模式)” 选项，点击开启。如果是 Windows 系统，首次开启时系统会弹窗提示安装虚拟网卡适配器驱动，点击“允许”。开启后，即便是在 CMD 终端运行 curl、git clone 或是玩外服 Steam 战地联机，都不需要单独配置 1080 端口代理，整个操作系统全自动被透明加速。

2. 启用严格 DNS 防泄漏

在高级 DNS 设置中，确保将 Fallback DNS 设置为 https://1.1.1.1/dns-query 与 https://8.8.8.8/dns-query。流量光在订阅中内置了干净的加密解析，杜绝运营商 DNS 劫持和 SNI 嗅探阻断。

七、常见报错排查与新手避坑要点

在实际使用过程中，如果遇到突发断网或打不开网页，请按以下四步自检：

  • 排查一：系统时间不同步。这是 80% 新手“所有节点全红”的罪魁祸首。Windows 系统请按 Win + I 打开设置，搜索“日期和时间”，点击“立即同步”。
  • 排查二：与其他 VPN 软件冲突。同时开启电脑管家加速器、迅游加速器或其他旧版代理软件会导致系统网络栈端口（如 7890）冲突。请退出其他多余网络工具。
  • 排查三：订阅长时间未更新。由于国际海缆故障或运营商 IP 轮换，流量光后端会动态剔除劣质节点并补充新节点。建议在配置管理中右键点击订阅，选择“定时更新”设置为 12 小时自动同步。
