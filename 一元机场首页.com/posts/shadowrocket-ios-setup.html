Shadowrocket (小火箭) iOS 零基础配置教程：美区 ID 与节点一键导入全攻略

📅 发布时间：2026年11月 🏷️ 标签：小火箭教程 / Shadowrocket / iPhone科学上网 / iOS翻墙 ⏱️ 阅读时长：约 9 分钟 👁️ 浏览量：38,400+

对于广大的苹果 iPhone 与 iPad 用户而言，Shadowrocket（俗称“小火箭”）无疑是 iOS 生态中知名度最高、装机量最大、兼容性最出色的代理工具。它的图标是一只跃升的白色小火箭衬托着清爽的蓝色背景。

小火箭支持几乎所有的现代网络代理协议（SS、SSR、VMess、VLESS、Trojan、Hysteria 2、Snell 等），具备极其强大的规则分流引擎与极低的系统功耗。然而，许多苹果新手由于不了解海外 Apple ID 的机制，在 App Store 搜不到正版，甚至误下载了名字相似的李鬼山寨软件。本文将带你一步步安全搞定小火箭的下载、导入与日常使用。

一、前置准备：如何在 App Store 下载正版 Shadowrocket？

1. 切记：不要在国区 App Store 搜索！

由于中国大陆 App Store 的合规监管，小火箭早在数年前便已全网下架。如果你在国区 App Store 搜索“小火箭”或“Shadowrocket”，搜出来的全部都是恶意山寨甚至扣费木马软件！正版小火箭由开发者 Pan Guan (Shadow Launch Technology Limited) 官方发布，售价一般为 $2.99 美元。

2. 获取海外 Apple ID（美区/港区/日区）

要想下载正版小火箭，你必须拥有一个非国区的 Apple ID：

  • 途径一：自行免费注册美区 Apple ID（推荐）：在苹果官方网页（appleid.apple.com）直接注册，国家地区选择美国，无需绑定海外银行卡，付款方式选“None”（无），使用网上公开的美国免税州免税地址即可完成注册。
  • 途径二：在各大电商或合租平台获取已购小火箭的共享/独享 ID：如果急需使用，可购买已经买过小火箭的现成账号。

3. 登录并下载小火箭的注意事项（非常重要！）

绝对不要在 iPhone 的“设置 -> 登录 iPhone (iCloud)”中登录陌生账号！否则一旦该账号被锁，你的手机将面临变砖或被远程锁机的致命风险！

正确的安全姿势：仅打开桌面上的 “App Store” 蓝色软件图标，点击右上角的个人头像拉到最底部点击“退出登录”，然后在此处登录海外 Apple ID。下载完成小火箭后，立刻退回登录你自己的国内个人账号，小火箭软件依旧可以永久正常使用！

二、一元机场订阅导入与使用教程

方法 A：一键全自动唤醒导入（最推荐、最简单）

  1. 使用 iPhone 自带的 Safari 浏览器打开一元机场官网控制台，登录你的账户；
  2. 在控制台首页找到“便捷导入”区域，点击“一键导入到 Shadowrocket”；
  3. Safari 浏览器会弹窗询问：“在‘Shadowrocket’中打开此页吗？”，点击“打开”；
  4. 小火箭会自动启动并弹窗确认保存订阅配置，点击右上角“完成”；
  5. 所有全球高速节点列表瞬间全部呈现在小火箭首页！

方法 B：手动复制 URL 订阅导入

  1. 若无法自动唤醒，在一元机场后台点击“复制小火箭订阅链接”；
  2. 打开 Shadowrocket 首页，点击右上角的 “+” 加号；
  3. 在第一栏“类型” (Type) 中，点击展开并选择“Subscribe” (订阅)；
  4. 在“URL”输入框中长按并粘贴刚才复制的订阅链接，备注写“一元机场”，点击右上角“完成”；
  5. 小火箭会自动联网下载并刷新出所有可用节点。

三、日常启动连接与模式选择

1. 测速与选择节点

在小火箭节点列表上方，点击“连通性测试”或“Ping 测速”。小火箭会对每一个节点进行握手测速，延迟越低（数字越小、绿色）代表速度越快。轻点选中你想要使用的节点（节点前方出现小黄点即为当前选中）。

2. 首次开启 VPN 授权

在小火箭顶部打开“未连接”开关：

  • 首次开启时，iOS 系统会弹出系统级确认框：“‘Shadowrocket’想添加 VPN 配置”；
  • 点击“允许” (Allow)；
  • 根据系统提示，输入你的 iPhone 锁屏数字密码或通过 Face ID 验证；
  • 顶栏出现 VPN 小图标，开关变为绿色“已连接”，连接成功！

3. 路由分流模式一定要选“配置” (Config)

在小火箭主界面的“全局路由”处，有四种选项：

  • 配置 (Config) - 【强烈推荐】：这是小火箭的智能分流模式。被墙的海外网站自动走节点，微信、抖音、淘宝、美团等国内应用走直连。省电、省流量且国内 App 秒开！
  • 代理 (Proxy)：全局代理模式，所有流量全部走节点（非特殊需要请勿开启）。
  • 直连 (Direct)：相当于关闭加速，全部直连。

四、小火箭高阶优化技巧

1. 开启节点自动定时更新

进入小火箭底部“设置” -> “订阅” -> 开启“打开时更新”与“自动更新”。这样每次你打开小火箭，它都会静默向一元机场服务器拉取最新的容灾节点，彻底杜绝节点失效失联！

2. 解决开启小火箭后电量消耗快的问题

小火箭底层代码优化极其卓越，正常分流待机时每小时耗电不足 1%。如果在电池排行中发现小火箭耗电高，通常是因为开启了“脚本 (Script)”或“HTTPS 解密解密抓包”导致 CPU 高频运算。日常使用中关闭“MITM 解密”和无用的第三方复杂脚本即可保持全天清凉省电。
