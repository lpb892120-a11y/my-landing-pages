对于初次接触海外互联网的朋友来说，“科学上网”、“翻墙”、“机场节点”、“订阅链接”、“Clash / 小火箭”等词汇往往让人感到云里雾里。网络上的很多教程充斥着艰涩的技术术语，新手往往折腾了半天仍然无法正常打开 Google 或 YouTube。

一、科学上网的三大核心概念：通俗大白话拆解

在开始操作之前，我们先用最直观的比喻理解科学上网的基本原理：

1. 什么是“节点”与“机场”？

你可以把你在国内的电脑或手机想象成一辆“本地快递车”，而海外的 Google、ChatGPT 则是“海外仓库”。因为有防火墙（GFW）的存在，国内快递车直接开不过去。

节点：就是设立在海外（如香港、日本、新加坡、美国）的中转中继站。你的设备把加密包裹先发给这个中转站，由它帮你代取海外仓库的货物再原路送回给你。

机场：由于这种中转站的图标通常是一架纸飞机（源自早期 Shadowsocks 的图标），因此提供批量节点服务的平台被称为“机场”。比如一元机场就是一家拥有遍布全球优质中继站的现代化高可用机场。

2. 什么是“订阅链接”？

订阅链接本质上是一个特殊的网络网址（URL），它相当于一张“实时中转站通行证地图”。你在一元机场官网注册购买套餐后，后台会生成一个专属于你的订阅链接。你只要把这个链接复制到客户端软件中，软件就会自动下载并更新几十个甚至上百个全球节点，免去了手动一个一个输入的痛苦。

3. 什么是“客户端”？

客户端就是安装在你的手机或电脑上的控制中心软件。常见的有 Windows/Mac 上的 Clash Verge Rev、苹果 iPhone 上的 Shadowrocket (小火箭)、安卓手机上的 v2rayNG 或 Sing-box。客户端负责把订阅链接中的节点解析出来，并根据你的规则分流网络流量。

二、全平台客户端选择与极速上手教程

1. Windows 与 macOS 电脑端推荐：Clash Verge Rev

目前在电脑端，Clash Verge Rev 是界面最美观、内核最新、对新协议支持最完善的免费开源客户端：

  1. 从官方 GitHub 仓库下载对应操作系统的安装包并安装（Windows 下载 .msi 或 .exe，Mac 区分 Intel 芯片和 Apple Silicon M 系列芯片）。
  2. 登录一元机场用户后台，点击“一键订阅”，选择“复制 Clash 订阅链接”。
  3. 打开 Clash Verge，点击左侧菜单的 “订阅” (Profiles)，在上方输入框粘贴刚复制的链接，点击“保存”或“导入”。
  4. 回到主界面，点击开启 “系统代理” (System Proxy) 开关。
  5. 在“代理”面板中选择你想要的地区节点（如“香港 IEPL”或“新加坡专线”），打开浏览器访问 Google 或 YouTube，秒开即代表配置成功！

2. 苹果 iPhone / iPad (iOS) 推荐：Shadowrocket (小火箭)

由于苹果中国区 App Store 政策限制，科学上网客户端无法在国区直接上架。因此需要使用一个海外地区 Apple ID（如美区、日区、港区）：

  1. 在 Safari 浏览器中登录美区 Apple ID，前往 App Store 搜索下载“Shadowrocket”（通常售价 $2.99，也可以在各大渠道购买已购共享账号）。
  2. 打开一元机场官网后台，点击“一键导入到 Shadowrocket”，手机会自动唤醒小火箭并弹出“保存节点列表”确认，点击允许。
  3. 若无法唤起，可复制订阅链接，在 Shadowrocket 右上角点击“+”号，类型选择“Subscribe”，粘贴 URL 并点击完成。
  4. 在小火箭首页选中一个延迟较低的节点，打开顶部的连接开关，系统会提示“添加 VPN 配置”，输入手机锁屏密码确认即可连接。

3. 安卓 Android 手机推荐：v2rayNG 或 Sing-box

安卓系统最为开放，客户端安装毫无阻碍：

  1. 下载并安装最新版的 v2rayNG 安装包 (.apk)。
  2. 进入一元机场官网控制台，点击“复制 V2Ray 订阅链接”或点击“一键导入 v2rayNG”。
  3. 在 v2rayNG 界面点击左上角三道杠展开侧边栏，进入“订阅分组设置”，点击右上角“+”，将复制的链接粘贴在“可选地址 (url)”一栏，保存返回。
  4. 点击主界面右上角三个点，选择“更新订阅”，所有节点将立即刷新呈现在列表中。
  5. 点击右下角的圆形 V 悬浮按钮即可开启代理连接。

三、必知必会：什么是“分流模式”？（规则 vs 全局）

在客户端中，你通常会看到三种代理模式，选择错误的模式可能会导致国内应用变慢甚至微信/网银无法使用：

  • 规则模式 (Rule / PAC)：【强烈推荐】只有海外被封锁的网站（如 Google、YouTube、Twitter、GitHub）才走代理节点，访问百度、淘宝、微信、B站等国内网站完全走直连本地宽带。这样既省下了节点流量，又保证了国内 App 的极速响应。
  • 全局模式 (Global)：你设备上的所有网络请求无论国内外一律强制通过代理节点。只有在极少数特定排错或必须隐藏全部 IP 的情况下才开启，日常使用不推荐。
  • 直连模式 (Direct)：相当于关闭代理，所有流量完全走本地网络。

四、常见故障与小白避坑答疑

1. 为什么导入订阅后测速显示全部超时（Timeout）？

这通常是因为你设备的本地时间与国际标准时间存在偏差。V2Ray 和现代加密协议对时间同步要求极高，时间差超过 90 秒就会导致握手校验失败。请进入系统设置，开启“自动同步网络时间”，重新更新订阅即可恢复。

2. 为什么能打开 Google，但打开某些国内网页很卡？

请检查客户端是否不小心误切成了“全局模式”。请务必切换回“规则模式”或“分流模式”。此外，检查 DNS 设置是否开启了智能分流解析。

3. 为什么 ChatGPT 总是提示“Sorry, you have been blocked”？

OpenAI 严苛限制了数据中心机房 IP。如果节点使用的是廉价公有云机房 IP，就会被批量拦截。请在一元机场中选择带有“原生IP”或“ChatGPT解锁”标识的专线节点，即可秒进官网畅享智能对话。
