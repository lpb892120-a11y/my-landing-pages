Shadowrocket iOS配置完整教程

📅 2024-11-08 👁️ 3892 ⏱️ 8分钟

一、Shadowrocket简介

Shadowrocket（俗称"小火箭"）是iOS平台上最受欢迎的代理工具，支持Shadowsocks、V2Ray、Trojan等多种协议，功能强大且易于使用。

核心优势：

  • 支持多种主流协议
  • 界面简洁，操作方便
  • 规则分流功能强大
  • 支持订阅链接
  • 性能稳定，资源占用低
  • 一次购买，永久使用

二、准备工作

2.1 获取美区Apple ID

由于Shadowrocket在中国区App Store下架，需要使用美区或其他国家地区的Apple ID购买。

方式一：自己注册（推荐）

  1. 访问appleid.apple.com
  2. 点击"创建您的Apple ID"
  3. 国家/地区选择"美国"
  4. 填写信息，注意邮箱不要使用国内邮箱
  5. 验证邮箱和手机号
  6. 完成注册

方式二：购买成品账号

  • 从可信渠道购买已有账号
  • 价格通常10-20元
  • 注意账号安全，不要绑定个人信息

2.2 购买Shadowrocket

价格：$2.99（约20元人民币）

购买步骤：

  1. 在iPhone上打开"设置"
  2. 点击顶部头像，拉到底部选择"退出登录"
  3. 登录美区Apple ID
  4. 打开App Store
  5. 搜索"Shadowrocket"
  6. 点击购买（可能需要绑定付款方式）
  7. 下载安装

付款方式：

  • 美国信用卡
  • PayPal
  • 美区礼品卡（推荐）

三、配置Shadowrocket

3.1 导入订阅

方法一：通过订阅链接（推荐）

  1. 打开Shadowrocket
  2. 点击右上角"+"
  3. 类型选择"Subscribe"（订阅）
  4. URL粘贴订阅链接（从八戒机场获取）
  5. 备注填写机场名称
  6. 点击右上角"完成"

方法二：扫描二维码

  1. 点击左上角扫描图标
  2. 扫描机场提供的订阅二维码
  3. 自动添加订阅

3.2 更新订阅节点

  1. 返回主页
  2. 点击右上角刷新图标
  3. 等待节点更新完成
  4. 可以看到所有可用节点

3.3 选择节点

  1. 在节点列表中选择一个节点
  2. 点击节点右侧的小圆圈进行选中
  3. 可以点击节点查看详细信息
  4. 长按节点可以进行测速

3.4 启动连接

  1. 选好节点后，点击顶部的连接开关
  2. 首次连接需要允许VPN配置
  3. 输入iPhone密码或使用Face ID/Touch ID确认
  4. 状态栏出现VPN图标表示连接成功

四、规则配置

4.1 全局路由

点击底部"配置"标签，可以看到三种模式：

  • 配置（推荐）：根据规则智能分流
  • 代理：全局代理模式
  • 直连：全部直连，不走代理
  • 场景：根据不同场景自动切换

4.2 导入规则

Shadowrocket支持导入第三方规则：

  1. 点击"配置"标签
  2. 点击右上角"+"
  3. 输入规则URL
  4. 下载并应用规则

推荐规则：

  • Loon规则（兼容Shadowrocket）
  • ACL4SSR规则
  • 机场自带的优化规则

4.3 自定义规则

可以添加自定义规则：

  1. 点击"配置"
  2. 选择当前使用的配置
  3. 点击"编辑配置"
  4. 在"规则"部分添加自定义规则

规则语法示例：

# 域名规则
DOMAIN,google.com,Proxy

# 域名后缀规则
DOMAIN-SUFFIX,youtube.com,Proxy

# 域名关键字
DOMAIN-KEYWORD,google,Proxy

# IP段
IP-CIDR,192.168.0.0/16,DIRECT

# 地理位置
GEOIP,CN,DIRECT

# 最终规则
FINAL,Proxy

五、进阶功能

5.1 节点测速

单个节点测速：

  • 长按节点
  • 选择"测速"
  • 等待测速结果

批量测速：

  • 点击"连通性测试"
  • 选择要测速的节点
  • 一键测试所有节点

5.2 流量统计

  • 主页可以查看实时流量
  • 点击"数据"查看历史流量统计
  • 可以按应用查看流量使用

5.3 按需连接

可以设置特定应用才启用代理：

  1. 进入"设置"
  2. 点击"按需连接"
  3. 添加触发规则
  4. 只在使用特定应用时连接

5.4 DNS设置

优化DNS解析速度：

  1. 进入"设置"
  2. 点击"DNS"
  3. 添加自定义DNS服务器

推荐DNS：

  • 1.1.1.1（Cloudflare）
  • 8.8.8.8（Google）
  • 223.5.5.5（阿里）- 国内网站

六、常见问题

6.1 无法连接

解决方案：

  • 检查订阅是否过期
  • 尝试更换节点
  • 更新订阅获取最新节点
  • 检查网络连接
  • 重启Shadowrocket

6.2 速度慢

优化方法：

  • 使用测速功能选择最快节点
  • 切换到其他节点
  • 检查本地WiFi/4G网络
  • 避开使用高峰期
  • 联系机场客服

6.3 部分App无法使用

可能原因：

  • App不支持代理
  • 规则配置问题
  • 节点IP被封

解决方法：

  • 切换到全局代理模式
  • 更换其他节点
  • 调整规则配置

6.4 耗电问题

省电建议：

  • 不使用时断开连接
  • 关闭不必要的功能
  • 使用按需连接
  • 选择稳定的节点

七、使用技巧

7.1 场景模式

根据不同使用场景自动切换配置：

  • 工作场景：使用规则模式
  • 娱乐场景：使用全局模式
  • 省电场景：使用直连模式

7.2 订阅管理

  • 可以添加多个订阅作为备份
  • 定期更新订阅获取新节点
  • 删除不用的订阅释放空间

7.3 iCloud同步

  • 开启iCloud同步配置
  • 多设备间自动同步
  • 更换手机时快速迁移
