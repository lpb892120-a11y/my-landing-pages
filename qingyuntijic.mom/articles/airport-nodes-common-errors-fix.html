二、深度排查场景 1：节点全部超时 (Timeout / Handshake Failed)

很多新手一看到 Clash 节点列表全部显示红色的 Timeout，第一反应就是“天塌了，机场跑路了”。其实不然：

1. 核心病根：系统时间不同步

现代加密协议（Trojan、VMess、VLESS、Shadowsocks-2022）在建立安全握手时，必须校验客户端与服务端的时间戳。如果本地电脑的时间比标准北京时间快了 90 秒，加密握手包会被服务端无情丢弃，造成全部节点显示连接超时。

🛠️ 10秒修复时钟方法：

• Windows 用户：按快捷键 Win + i 打开设置 -> 点击【时间和语言】 -> 【日期和时间】 -> 确认时区为 (UTC+08:00) 北京，重庆，香港特别行政区 -> 点击【立即同步】按钮，看到绿色小对勾即可。
• macOS 用户：进入【系统设置】 -> 【通用】 -> 【日期与时间】，关闭再重新打开【自动设置日期与时间】。

2. 检查套餐有效性

登录 青云梯控制台，确认套餐是否处于有效服务期内，以及本月的高速专线流量是否已被大文件下载耗尽。

三、深度排查场景 2：关闭代理后无法上网 (注册表死锁)

这是 Windows 用户最常经历的噩梦：退出 Clash 或关机重启后，突然所有国内网页（甚至连路由器后台）都无法访问，只有重新打开 Clash 才能勉强上网。

根本机理：

当 Clash 开启【系统代理】时，它在 Windows 注册表中将代理服务器地址改成了 127.0.0.1:7890。如果软件被强行杀进程或意外崩溃，注册表中的代理开关没有被顺畅改回“关闭”，系统就会持续向已经关闭的 7890 端口发送请求，导致所有浏览器彻底断网。

一招自愈步骤：

  1. 按 Win + R 键输入 inetcpl.cpl 打开经典的【Internet 属性】窗口。
  2. 切换到【连接】选项卡，点击右下角的【局域网设置 (LAN Settings)】。
  3. 取消勾选【为 LAN 使用代理服务器】。
  4. 勾选顶部的【自动检测设置】，点击【确定】并保存。立刻恢复正常直连！

四、深度排查场景 3：DNS 污染与 198.18.0.0/16 Fake-IP 迷局

Clash 默认采用革命性的 Fake-IP 模式。在该模式下，当你发起海外域名请求时，Clash 内核会瞬间返回一个形如 198.18.x.x 的保留虚拟假 IP，并在内核内部建立域名映射表。

⚠️ Fake-IP 缓存引发的灵异现象

如果你 Ping 某个海外网站发现返回的是 198.18.0.x，这是完全正常的 Fake-IP 机制，切勿以为中毒。但如果频繁更换网络环境（例如从公司 Wi-Fi 换到手机热点），本地 DNS 缓存可能错乱。解决方法：在 Windows 命令行中以管理员身份运行 ipconfig /flushdns，清空本地 DNS 解析缓存即可。

五、深度排查场景 4：订阅拉取 500 / 403 / 证书报错

当在客户端中点击更新订阅时，偶尔会弹出红色警告：

  • 报错 403 Forbidden / 401 Unauthorized：您的青云梯账号可能已被重置了订阅 Token（如在后台点击过【重置订阅链接】）。解决方法：登录后台重新点击【复制订阅链接】并覆盖客户端旧配置。
  • 报错 500 Internal Server Error 或 Connect ETIMEDOUT：说明您本地的网络运营商正在对订阅 API 域名进行间歇性干扰。解决方法：打开客户端原有的有效节点（或连接手机热点），开启代理后再点击更新订阅；或者联系青云梯客服获取专属的免翻墙备用下发地址。
