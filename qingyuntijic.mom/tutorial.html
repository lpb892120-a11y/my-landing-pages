一、Windows 系统详细配置指南 (Clash Party & Clash Verge)

在 Windows 10 / 11 操作系统中，传统的 Clash for Windows (CFW) 已经逐渐淡出舞台，目前社区最受推崇且维护积极的客户端是 Clash Party 与 Clash Verge Rev。两者均内置了新一代 Mihomo (Clash Meta) 内核，具备极低的内存开销与强悍的 TUN 虚拟网卡功能。

💡 为什么推荐优先使用 Clash Party？

Clash Party 采用了极简现代化的 UI 设计语言，支持青云梯专属的一键订阅唤起协议，新用户无需手动复制黏贴长链接，点击即可自动配置好规则分流，极其适合新手出海使用。

操作步骤：

  1. 进入 青云梯官网 登录个人控制台。
  2. 在用户后台首页找到【便捷导入】区域，点击【下载 Windows 客户端】获取软件安装包。
  3. 解压并安装软件，双击启动。首次运行若弹出 Windows 防火墙警告，请勾选【专用网络】与【公用网络】并点击【允许访问】。
  4. 返回青云梯后台，点击【一键导入到 Clash Party】，客户端会自动弹窗并显示正在拉取配置文件。
  5. 导入成功后，在左侧导航点击【代理】，展开【节点选择】分组，挑选一个延迟较低的专线节点（如：🇭🇰 香港 IEPL 01 或 🇯🇵 日本 01）。
  6. 切换到软件首页，打开【系统代理 (System Proxy)】开关。此时打开浏览器即可流畅访问 Google、YouTube 等网站。
⚠️ 遇到提示“系统时间不正确”或“Handshake Failure”怎么办？

VMess/VLESS/Trojan 等加密协议对本地系统时间误差有严苛限制（必须在 60 秒以内）。请按 Win + i 打开系统设置 -> 【时间和语言】 -> 点击【立即同步时钟】即可恢复正常。

二、macOS 苹果电脑配置指南

针对搭载 Apple Silicon (M1/M2/M3/M4) 及 Intel 处理器的 Mac 用户，我们推荐使用 Clash Verge Rev for Mac。

  1. 根据您的 Mac 芯片架构下载对应 .dmg 安装包（Apple Silicon 请下载 aarch64 版本，Intel 芯片请下载 x64 版本）。
  2. 将应用程序图标拖入 Applications 文件夹完成安装。
  3. 打开 Mac 系统【系统设置】 -> 【隐私与安全性】，若提示“无法打开，因为不是来自已标识的开发者”，点击【仍要打开】。
  4. 在青云梯后台复制通用订阅地址，在 Clash Verge 的 Profiles 界面粘贴并保存。
  5. 在设置中将代理模式设为【规则 (Rule)】，勾选【系统代理】即可开始冲浪。

三、iOS 苹果手机配置指南 (Shadowrocket 小火箭)

在 iPhone 或 iPad 上，Shadowrocket（俗称小火箭）是公认体验最佳的科学上网工具。因政策原因，中国大陆地区 App Store 无法搜索下载，您需要准备一个海外区域（如美区、日区、港区）的 Apple ID。

  1. 打开 App Store，退出原有国区账号，登录海外 Apple ID。
  2. 在搜索栏输入 Shadowrocket 并下载正版小火箭（认准图标为一个白色发射小火箭，背景为浅蓝色）。
  3. 在 Safari 浏览器中登录青云梯官网后台，点击【一键导入到 Shadowrocket】。小火箭将自动弹起并加载所有节点。
  4. 在主界面下方的【全局路由】中确认选择为【配置】（切勿选择“全局代理”，否则国内应用会变慢且白白消耗套餐流量）。
  5. 轻点顶部的连接滑动开关，iOS 弹出“Shadowrocket 想要添加 VPN 配置”提示，点击【允许】并验证锁屏密码或 Face ID 即可。

四、Android 安卓系统配置指南 (Clash Meta for Android)

安卓手机开源开放，推荐安装 Clash Meta for Android (CMFA)。

  1. 下载 .apk 安装包并在手机上授予安装权限。
  2. 在青云梯后台复制订阅链接，打开 CMFA -> 点击【配置 (Profiles)】 -> 点击右上角加号 -> 选择【从 URL 导入】。
  3. 名称填入 青云梯专线，URL 处粘贴订阅链接，自动更新周期建议填入 1440 分钟（即 24 小时自动更新），点击右上角保存。
  4. 返回主界面，点击【启动】，首次连接同意建立本地 VPN 连接。
  5. 在【代理】页面挑选心仪节点，尽享全天候无缝加速。
