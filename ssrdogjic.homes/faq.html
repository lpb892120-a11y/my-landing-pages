🔰 1. 新手入门与核心概念

什么是 Clash 机场？如何开始使用？

+

Clash 机场是专门提供高速代理节点订阅的服务商。使用流程仅需四步：
1. 访问 ssrdog 官网 注册账号并选购套餐。
2. 按照操作系统下载对应的客户端（如 Windows/Mac 推荐 Clash Party 或 Clash Verge，iOS 推荐 Shadowrocket，Android 推荐 Clash Meta）。
3. 在用户后台复制订阅链接导入至客户端。
4. 选择规则模式（Rule）并开启代理即可秒开外网。

为什么大家都推荐用“规则模式 (Rule)”而不是“全局模式 (Global)”？

+

因为规则模式最智能、最省流量！它内置了精准的路由规则，访问百度、微信、淘宝等国内网站时自动走本地直连，不绕道国外；只有访问 Google、YouTube、GitHub、ChatGPT 等海外受限服务时才经由专线加速，两者互不影响。

ssrdog 机场安全吗？会不会泄露我的上网隐私？

+

绝对安全！ssrdog 严格执行行业最高标准的零日志（No-Logs）政策，不记录任何访问历史和传输内容。所有通信均由军事级强加密协议保护，服务器位于海外隐私保护法区。

⚡ 2. 节点与专线网络质量

什么是 IPLC / IEPL 专线？它比普通节点强在哪里？

+

IPLC 是电信运营商提供的跨境点对点封闭式内网光纤，不经过公网国际公共出口与 GFW 防火墙审查。其优势是：晚高峰绝对零丢包、延迟低至极限（如深圳到香港仅 14ms），即使在敏感时期也 100% 稳定在线。

为什么播放 Netflix 提示只能看自制剧？ssrdog 如何解决？

+

普通机场采用的是机房 IP，被流媒体数据库列入了黑名单。ssrdog 在海外节点部署了当地纯净原生住宅 IP，能够全区解锁 Netflix 非自制剧、Disney+ 以及 YouTube 4K/8K 超高清画质。

使用 ChatGPT / Claude 会弹出 Access Denied 报错吗？

+

不会！ssrdog 专门调优了针对 OpenAI 与 Anthropic 的纯净反风控专线，无任何 Cloudflare 5秒盾阻拦，保障大语言模型交互流畅不掉线。

🛠️ 4. 客户端配置与排错急救

订阅更新提示 403 Forbidden 怎么回事？

+

通常是因为套餐到期欠费或当月流量耗尽。请先登录 官网后台 检查账号状态，若正常可尝试重新复制最新订阅 URL 重新导入。

节点全部显示“Timeout 超时”或 0ms 怎么解决？

+

90% 的原因是本地电脑系统时间不准！加密协议严格依赖时间戳，请在 Windows/Mac 设置中点击“立即同步时间”。此外检查杀毒软件是否拦截了代理内核进程。

关掉代理后电脑打不开任何国内网页了怎么办？

+

这是因为关闭软件前未取消系统代理，导致残留了 127.0.0.1:7890 代理设置。打开 Windows“设置 → 网络和 Internet → 代理”，将“手动设置代理”开关关闭即可恢复。
