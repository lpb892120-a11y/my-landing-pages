Windows Clash教程：Clash Verge & Clash Party 完整配置图文指南

📅 最后更新：2026-11-08 💻 适用平台：Windows ⏱️ 阅读时长：约 6 分钟 🛡️ ssrdog 官方验证保障
💡 适用提示：

推荐使用 Windows 10 或 Windows 11 64位系统。本教程以当前最主流的 Clash Verge Rev 及 Clash Party 为基准编写。

一、客户端下载与安装

在 Windows 环境下，目前最受推崇的客户端是 Clash Verge Rev 或新一代极简美观的 Clash Party。它们采用全新开源内核，全面支持 VLESS、Trojan 等高抗干扰协议。

下载 .exe 安装包后，双击运行并按照提示安装到默认目录即可。如遇 Windows Defender 提示拦截，点击“更多信息”并选择“仍要运行”。

二、导入 ssrdog 订阅节点

1 复制订阅地址：登录 ssrdog 用户中心，在仪表盘主页找到“订阅管理”，点击“复制 Clash 订阅链接”。
2 添加配置源：打开客户端，进入左侧 Profiles (配置) 页面，在顶部 URL 框粘贴订阅链接，点击 Import (导入) 或 Download。
3 激活配置文件：在配置列表中选中刚导入的 ssrdog专线，右键或单击将其设为当前生效配置。

三、模式选择与开启代理

4 挑选分流模式：切换至 Settings (设置)，代理模式选择 Rule (规则模式)。此模式会自动放行微信、百度等国内应用，海外流量走专线代理。
5 开启系统代理开关：在主界面开启 System Proxy (系统代理)。打开浏览器访问 YouTube 或 Google，网页瞬间秒开即代表配置成功！

❓ Windows 客户端常见疑问

Windows 开机能让 Clash 自动启动并开启代理吗？

+

可以！在设置中开启“开机自启 (Start with Windows)”和“静默自启”，即可实现开机后全天候无感科学上网。

为什么打开代理后，微信无法收发图片了？

+

请检查是否误开启了“Global (全局模式)”。切换为“Rule (规则模式)”即可自动直连国内应用。
