macOS Clash教程：苹果电脑 Clash Verge / ClashX Meta 配置指南

📅 最后更新：2026-11-08 💻 适用平台：macOS ⏱️ 阅读时长：约 6 分钟 🛡️ ssrdog 官方验证保障
💡 适用提示：

原生支持 macOS Sonoma、Sequoia 及所有搭载 M 系列 Apple 芯片的 Mac 电脑，效能卓越，耗电极低。

一、Mac 客户端安装与安全授权

下载对应芯片架构的 .dmg 镜像包（M1-M4 用户请下载 arm64 版本，Intel 用户请下载 x64 版本），双击打开并将软件图标拖入“Applications”文件夹。

初次打开时如果系统提示“无法打开，因为 Apple 无法检查其是否包含恶意软件”，请打开 Mac 系统设置 → 隐私与安全性，下滑点击“仍要打开”即可正常启动。

二、导入 ssrdog 专线订阅

登录 ssrdog 仪表盘 复制订阅链接。在 Mac 客户端的“Profiles (配置)”中粘贴并回车下载。下载完成后，所有香港、日本、新加坡、美国专线节点将整齐罗列。

三、状态栏控制与规则分流

Mac 客户端会在顶部状态栏常驻一个猫咪或飞机图标。点击状态栏图标，勾选 “规则模式 (Rule)”，然后点击 “设置为系统代理”。此时 Safari 或 Chrome 浏览器已全面具备科学上网能力。

❓ macOS 客户端常见疑问

Mac 电脑合上盖子休眠后，唤醒偶尔无法联网？

+

在客户端设置中将内核切换为“Meta 内核”，并开启“休眠自动重启代理连接”，能够完美解决休眠唤醒后的套接字重连问题。

Mac 终端 (Terminal) 如何走代理？

+

在设置中开启“Tun Mode (虚拟网卡模式)”并安装辅助驱动，整机终端命令（如 git push、brew update）将全自动走专线加速。
